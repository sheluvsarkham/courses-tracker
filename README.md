# Трекер курсов

Настольное приложение для Windows на Go и Wails. Интерфейс позволяет вести список учебных курсов, искать и фильтровать их, отмечать завершение и следить за статистикой.

## Возможности

- добавление курсов с описанием, категорией, уровнем и длительностью;
- просмотр списка курсов;
- отметка курса как завершённого;
- удаление курса;
- просмотр статистики по курсам;
- регистрация и вход в локальный аккаунт;
- раздельный список курсов для каждого аккаунта;
- bcrypt-хеширование паролей;
- локальное хранение аккаунтов и курсов в JSON-файлах;
- поиск по названию, описанию и категории.

Имя пользователя: 3–32 латинских символа, цифры, точка, дефис или подчёркивание. Пароль: 8–72 байта. Аккаунты доступны только в этой копии приложения на текущем компьютере; синхронизации между устройствами нет.

## Требования

- Windows 10/11 с WebView2 Runtime;
- Go 1.22 или новее.

## Запуск

Клонируйте репозиторий и перейдите в его папку:

```bash
git clone <URL-репозитория>
cd course-tracker
```

Запустите приложение из исходников:

```bash
go run ./cmd/app
```

Соберите оконный `.exe` без консольного окна:

```powershell
go build -tags production -ldflags="-H windowsgui" -o CourseTracker.exe ./cmd/app
```

При первом запуске существующий `data/courses.json` переносится в профиль первого созданного аккаунта. Аккаунты хранятся в `%AppData%\CourseTracker\users.json`, а курсы каждого пользователя — отдельно в папке `%AppData%\CourseTracker\accounts`.
